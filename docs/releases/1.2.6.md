# SOYAM 1.2.6 — Hotfix

- Исправлен запуск треков щелчком по названию в списках библиотеки, плейлистов, альбомов, поиска и страницы артиста.
- Исправлена обработка составных ID Яндекса при запуске списка. Сохраняется порядок треков для кнопок «Назад» и «Вперёд»; кэшированные данные используются без повторной загрузки всего списка.
- Добавлена отметка E для взрослых треков по данным Яндекс Музыки: в списках, на главном экране и нижней панели. Признак сохраняется в кэше; старые данные обновляются с сервера.

Windows x64: установщик `soyam-windows-setup.exe` и портативная версия `soyam-windows-x64-portable.zip`.
