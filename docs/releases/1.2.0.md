# SOYAM 1.2.0

## Что нового

- В настройках появилась кнопка «Проверить обновления».
- В установленной Windows-версии найденное обновление скачивается автоматически, с показом прогресса. Перед запуском проверяются размер файла и SHA-256. После загрузки нажмите «Установить»: SOYAM закроется и откроет установщик.
- Портативная версия продолжает открывать страницу релиза для ручного обновления.
- Обложки текущего трека на главном экране и нижней панели запускают «Мою волну по треку». При наведении появляется затемнение и значок волны.
- Кнопки «Слушать» в альбомах, плейлистах и на странице исполнителя показывают состояние воспроизведения и переключаются на паузу.
- Автоматическое скрытие боковой панели работает на всех страницах. Панель плавно сворачивается к выбранной кнопке и уходит влево. Зона раскрытия немного больше самой панели.
- Громкость можно регулировать колёсиком над значком громкости или ползунком. Число следует над бегунком и скрывается после остановки прокрутки.
- Список любимых треков выровнен по границам поисковой строки без смещения полосы прокрутки.
- Размер имени исполнителя на нижней панели приведён к размеру в библиотеке.
- Убрана подпись «Изменения сохраняются в своём профиле» из эквалайзера.

## Установка и обновление

- **Установщик Windows x64:** `soyam-windows-setup-1.2.0.exe`.
- **Портативная версия Windows x64:** `soyam-windows-x64-1.2.0-portable.zip`. Распакуйте весь архив и запустите `soyam.exe`.
- Оба варианта содержат библиотеки Microsoft Visual C++ x64. Данные аккаунта и скачанные треки сохраняются в профиле Windows.
- Для каждого файла приложена контрольная сумма `.sha256`.

Для перехода с версии 1.1.0 скачайте установщик этого релиза вручную.
Автоматическая загрузка следующих обновлений доступна начиная с версии 1.2.0.
