# SOYAM 1.2.1

- Значок программы перекрашен в зелёный. Обновлены значки окна, трея и экрана настроек.
- Нижняя панель стала немного прозрачнее, сохранив размытие фона.
- На главной обложке под значком волны появилась подпись «Волна по треку».
- Подсветка кнопки профиля на боковой панели стала круглой.
- В настройках исправлено описание источников: «Включенные источники для поиска текста.»
- README получил единый раздел «Установка» с кнопкой скачивания последнего установщика. Android и Linux обозначены как «Скоро».

## Windows x64

- `soyam-windows-setup-1.2.1.exe` — установщик.
- `soyam-windows-setup.exe` — тот же установщик под постоянным именем для кнопки скачивания в README.
- `soyam-windows-x64-1.2.1-portable.zip` — портативная версия. Распакуйте весь архив и запустите `soyam.exe`.
- Рядом с каждым файлом опубликована контрольная сумма SHA-256.

Данные аккаунта и скачанные треки сохраняются. В установленной SOYAM 1.2.0
можно проверить обновление в настройках и скачать установщик автоматически.
