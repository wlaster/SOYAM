# «Меньше ИИ» в YAYMA

В настройках добавлен раздел «Рекомендации» и переключатель «Меньше ИИ». Значение читается из аккаунта Яндекс Музыки. Сохранение считается успешным только после ответа сервера и контрольного чтения.

## Подтверждённый протокол официального клиента

Исследован публичный клиент music.yandex.ru, версия v4.1722.0, 26 октября 2026 года:
- [Настройки](https://music.yandex.ru/settings).
- [Запрос настроек аккаунта](https://yastatic-net.ru/s3/music-frontend-static/music/v4.1722.0/_next/static/chunks/97131-53377b71d13e5e83.js).
- [Параметры сессии рекомендаций](https://yastatic-net.ru/s3/music-frontend-static/music/v4.1722.0/_next/static/chunks/61395-454f91c8301ae3c1.js).

Протокол:
- GET /account/settings → result.aiContentReductionEnabled.
- POST /account/settings?aiContentReductionEnabled=true или false. Передаётся только изменяемый параметр, остальные настройки аккаунта не перезаписываются.
- POST /rotor/session/new: при включении в JSON добавляется aiContentReductionEnabled: true. При выключении параметр опускается, как в официальном клиенте.

При изменении создаётся новая сессия волны в фоне. Текущий трек, его позиция и состояние воспроизведения сохраняются; будущая очередь заменяется рекомендациями новой сессии. Ответы от устаревших запросов не применяются после смены коллекции или настройки. Если обновить очередь не удалось, приложение сообщает об этом; сохранённая настройка действует при следующем запуске волны.

В интерфейсе нет оптимистического подтверждения: во время запроса переключатель заблокирован, при ошибке доступно повторное чтение серверного состояния.

## Проверки

- Все 145 обычных тестов Rust прошли, включая проверку сохранения текущей песни и позиции при замене рекомендаций.
- Отдельный сетевой тест использовал реальные методы Rust: переключил настройку в оба состояния, подтвердил контрольным чтением, создал рабочие сессии волны для обоих вариантов. Исходное значение аккаунта «включено» восстановлено.
- Два теста протокола проверяют обработку false, отсутствие поля, неверный тип и JSON параметра волны.
- Все 14 тестов Flutter прошли, включая загрузку серверного значения, блокировку повторного сохранения и восстановление после ошибки.
- Анализ изменённых файлов не выявил замечаний. Windows Release собран; сборка, архив и ярлык обновлены.
- В эту сборку также включён более матовый фон нижней панели: усилено размытие и снижена прозрачность, особенно при показе текста песни.

Токены и персональные ответы сервера в этот документ не записывались.
