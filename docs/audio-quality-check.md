# Проверка кодеков и битрейта

Проверены ответы авторизованного API и до 512 КиБ начала аудиофайла независимым анализатором заголовков. Интерфейс и пользовательские сценарии не запускались. API принимает кодек и уровень качества, а не точный битрейт. Для FLAC битрейт переменный. У AAC класс 192 кбит/с может иметь средний битрейт около 195–201 кбит/с по метаданным файла.
