# Недоступные треки (Windows)

Переключатель: **Настройки → Рекомендации → Недоступные треки**. По умолчанию выключен; состояние сохраняется.

- Поиск объединяет Яндекс, Hitmos (`hitmos.me` перенаправляет на `ru.hitmoz.org`).
- На странице артиста добавляются найденные внешние песни с точным совпадением имени исполнителя. Полнота дискографии не гарантируется.
- Несколько исполнителей отображаются отдельно. Внешний дубль скрывается только при совпадении с доступным оригиналом Яндекса по исполнителям, версии и длительности. Подмены (`substituted` или отличающийся `realId`) считаются недоступными оригиналами и не скрывают внешнюю запись. Студийные записи показываются перед live, если концертная версия не запрошена явно.
- Списки недоступных треков расположены перед обычными и плавно раскрываются и сворачиваются.
- Красная метка **U** означает отсутствие записи в каталоге Яндекса либо недоступность оригинала. Метка **E** сохраняет своё значение.
- Недоступные записи из существующих альбомов и плейлистов ищутся по исполнителю, названию, версии и длительности. При неоднозначном совпадении подмена не выполняется.
- Внешние записи воспроизводятся собственным плеером. Временные аудиоссылки обновляются со страницы источника, в настройках сохраняются только метаданные и адрес страницы.
- Внешние записи можно добавлять в «Любимое»: они сохраняются локально и переживают синхронизацию с Яндексом и перезапуск. В плейлисты Яндекса их отправить нельзя: у сервиса нет соответствующих ID. Для недоступного оригинала с ID Яндекса привычные действия сохраняются.
- В Мою волну внешние записи не добавляются. При выключении настройки внешнее воспроизведение останавливается.


**Пустой поиск Hitmos:** если публичный текстовый поиск сайта ничего не возвращает, вставьте в строку поиска клиента ссылку на песню или исполнителя Hitmos. Клиент прочитает карточку и связанный каталог артиста, сохранит метаданные и будет учитывать найденные версии при последующих обычных поисках. Конкретные песни и исполнители в коде не прописаны.

Сайты могут менять разметку или не иметь нужной песни. Ошибка одного источника не отменяет результаты остальных. Клиент не придумывает отсутствующие альбомы и их состав на основании обычного поиска песен.
