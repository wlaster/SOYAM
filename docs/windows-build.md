# Windows: сборка и тексты песен

Готовая сборка: `dist/YAYMA-Windows-current/yayma.exe`. Ярлык на рабочем столе: «YAYMA (новая сборка)». Архив: `dist/yayma-windows-lyrics.zip`.

## Источники и отображение

Яндекс Музыка, LRCLIB, BetterLyrics, YouLyPlus, Lyrics.ovh и Genius. В меню доступны только включённые источники. Авто параллельно проверяет включённые источники, предпочитает настоящий синхронизированный текст и сохраняет обычный как резерв. Отказ одного сайта не останавливает остальные запросы.

Синхронизация только по строкам: таймкоды слов не передаются в интерфейс. Исходные таймкоды строк сохраняются, выделение опережает часы воспроизведения на 300 мс. Перемотка назад корректно возвращает выделение. Текст без таймкодов прокручивается вручную.

## Статистика исполнителей и качество (25 октября 2026)

На странице исполнителя Яндекс отображается из `result.stats.lastMonthListeners` ответа `artists/{id}/brief-info`. Старое `ratings.month` — место в рейтинге, а не аудитория; оно больше не используется как число слушателей. Число добавлений в любимые также не называется слушателями.

Spotify запрашивается отдельно: ссылка из профиля исполнителя или однозначное совпадение имени через MusicBrainz, затем публичная страница Spotify. Неизвестные, неоднозначные и недоступные значения показываются прочерком, а не нулём. Официальный Web API Spotify не имеет поля monthly listeners. При текущем подключении lookup Spotify не удалось подтвердить; сохранённых и вымышленных чисел нет.

Живой тест: Imagine Dragons — 4 547 037 слушателей Яндекса, старая позиция рейтинга 182. Запросы качества для одного локально известного трека: lq — HE-AAC 64 кбит/с; nq — AAC 192 кбит/с; lossless-запрос получил от сервера nq 192 кбит/с. Доступность lossless зависит от ответа сервиса. URL и подготовленные сессии теперь разделяются по запрошенному качеству, включая устаревшие ответы предзагрузки. Офлайн-файлы сохраняют качество, в котором скачаны.

Длинные строки синхронизированного текста переносятся при прежнем размере шрифта. Высота строк и расстояние прокрутки вычисляются по тексту; активная строка центрируется на середине окна, на уровне лупы боковой панели. Кнопка скачивания коллекций сама открывает MenuAnchor, поэтому штатная анимация M3EButton получает наведение и нажатие.


## Уточнения качества и оформления

Для высокого качества теперь проверяется фактический ответ: FLAC либо битрейт выше 192 кбит/с (включая AAC 256 и MP3 320). Если get-file-info предлагает стандартную версию, дополнительно проверяются полные MP3-варианты download-info. При отсутствии HQ выбор не применяется к текущему треку: воспроизведение и прежняя настройка сохраняются, пользователь получает уведомление. Подготовка следующего трека и скачивание также не маркируют 192 как HQ.

Логотипы Яндекс Музыки и Spotify скачаны из официальных бренд-наборов, пути источников находятся в `src/assets/icons/SOURCES.md`. Картинки отображаются через ClipOval. Подсказки и приписка / мес. у счётчиков убраны. Опережение активной строки увеличено до 400 мс.


## Восстановлена прежняя логика качества

По просьбе пользователя последняя строгая проверка HQ отменена: Low запрашивает lq, Normal — nq, High — lossless; приложение принимает доступную версию, которую вернул сервис. Проверка HQ перед переключением, блокировка 192 кбит/с и дополнительные MP3-поиски для HQ удалены. Сохранены исправления кэша предзагрузки по качеству, внесённые ранее.

Счётчики исполнителя: запятые между разрядами (`4,381,745 в месяц`, `118,055 в любимых`). Пользовательские тесты не проводились. Результаты четырёх песен и пяти критериев: `audio-quality-check.md` и `audio-quality-check.json`.
